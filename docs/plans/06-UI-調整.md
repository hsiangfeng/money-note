# Money Note UI 調整計畫：暖色紙本帳冊

## Context

`day-16/money-note` 的功能已經照 SPEC 第 3 節做完了，但外觀還停在 Tailwind 預設的 slate 藍白配色 —— 那是後台管理介面的預設值，跟「一個人站在超商門口手記一筆流水帳」的產品性格對不上。

這次要把視覺方向換成**暖色紙本帳冊**：安靜、俐落、數字優先。做法上只動標記結構與樣式，資料模型、`useRecords.js`、`stats.js` 的計算邏輯一律不碰。

順帶處理四件目前不合格的事：觸控目標普遍小於 44px（月份箭頭 36px、「本月」按鈕 26px）、沒有任何 `:focus-visible` 樣式、沒有處理 `prefers-reduced-motion`、桌機寬度卡在 448px。

已經跟使用者確認過的四個方向：內嵌常駐表單、分頁移進頁面流、換暖色墨系分類色票、明體標題＋黑體內文＋等寬數字。

## 一、設計方向

### 為什麼是帳冊，不是「暖色系 app」

真正的紙本帳冊有三個結構特徵，全部都帶著資訊、不是裝飾：**橫向欄位線**（一列一筆）、**金額欄的直線**（錢跟文字分屬不同欄）、**合計的雙底線**（會計慣例：單線是小計，雙線是總計）。這三樣拿來當版面骨架，畫面就不需要陰影、圓角、色塊來製造層級。

**簽名元素：合計雙底線 + 貫穿明細的金額欄直線。** 全站只有這一個記憶點，其他一律安靜。

### 色票（`@theme` token）

| Token | 值 | 用途 |
|---|---|---|
| `--color-paper` | `#F3EFE7` | 頁面背景 |
| `--color-card` | `#FFFDF8` | 卡片、表單、明細底 |
| `--color-ink` | `#1F2925` | 主要文字、合計雙線 |
| `--color-ink-soft` | `#56625C` | 次要文字、欄頭、標籤 |
| `--color-ledger` | `#245C4A` | 主要動作（存檔、已選分類、目前分頁、focus ring） |
| `--color-clay` | `#9A4F20` | 重點：本月總支出那個數字 |
| `--color-alert` | `#962E2E` | 只給刪除，不做他用 |
| `--color-rule` | `#DCD5C8` | 帳冊線（實色，不用透明度疊色，避免疊在卡片上變兩種灰） |
| `--color-rule-soft` | `#EBE5DA` | 明細列之間的細分隔線 |

不用漸層、不用玻璃、不用彩色陰影。唯一的「深度」來自線條粗細與紙／卡兩層底色差。

### 字型（全部系統字，不載遠端）

```css
--font-sans:  -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang TC",
              "Noto Sans TC", "Microsoft JhengHei", sans-serif;
--font-title: Georgia, "Songti TC", "Noto Serif TC", "Source Han Serif TC", serif;
--font-mono:  ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace;
```

- **明體只出現在三個地方**：`Money Note` 標題、區塊標題（記一筆／支出明細／分類佔比）。用得少才有味道。
- **所有金額一律 `--font-mono` + `tabular-nums`**：字寬固定，明細的金額欄才對得成一直排；這是「數字優先」在排版上的具體做法，不是選一個好看的字。
- 月份標籤、筆數、百分比一樣走 `tabular-nums`，切月時數字不跳寬。

### 分類色票（`categories.js` 的 `color` 欄位）

六色全部從同一組墨水裡調，圓餅圖不引進外來色相；明度也拉開，色覺障礙靠深淺一樣分得出來。

| id | 名稱 | 新色 | 舊色 |
|---|---|---|---|
| `food` | 飲食 | `#9A4F20` 赭石 | `#f97316` |
| `transport` | 交通 | `#245C4A` 墨綠 | `#0ea5e9` |
| `daily` | 日用 | `#6B7A52` 苔綠 | `#14b8a6` |
| `entertainment` | 娛樂 | `#5D5480` 靛 | `#a855f7` |
| `medical` | 醫療 | `#8E3B4A` 玫瑰 | `#ef4444` |
| `other` | 其他 | `#8A8377` 暖灰 | `#94a3b8` |

fallback 色 `#cbd5e1` → `#B8AFA0`。**`id` 與 `name` 一個字都不動**，`localStorage` 裡的資料完全不受影響。

### SPEC 第 10 節要補的五列（2026-08-22）

1. UI 改走「暖色紙本帳冊」方向 —— 原本的 slate 藍白是框架預設值，跟單人手記流水帳的性格對不上。
2. 記帳表單由 bottom sheet 改為記帳頁內嵌常駐，移除右下浮動新增按鈕 —— 表單常駐後記一筆從四步變三步；同時省掉遮罩、離場閘門、safe-area 三處只為 sheet 存在的處理。驗收條件 1 文字同步調整。
3. 分頁列由固定底部改為頁面內索引標籤 —— 固定底列是 app chrome，跟紙頁方向衝突；移除後不再需要墊高與 safe-area 疊算。
4. 分類 `color` 換成暖色墨系色票 —— Tailwind 預設色在 `#F3EFE7` 上偏螢光，天藍與紫會把畫面拉回藍白後台。`id` 與 `name` 未動，資料不受影響。
5. 統計頁移除重複的「本月支出／記帳筆數」兩張卡，翻掉 2026-08-16「不去重」那條 —— 該決策成立時頁首只有總支出、筆數只在統計頁；現在頁首摘要同時有兩個數字且就在正上方。

## 四、驗收清單

### A. 功能不能壞：SPEC 第 7 節十一條（逐條走過，不是看畫面）

1. 手機開啟，表單就在畫面上 → 輸入 120 → 點「飲食」→ 存檔，三個動作內記完一筆
2. 新記的那筆立刻出現在明細最上方，頁首總額同步增加
3. 圓餅圖扇形大小與明細百分比正確反映該月各分類金額
4. 點明細任一列可以改金額／分類／日期／備註，存檔後明細與統計同步更新
5. 刪除會先跳確認（表單內就地展開），確認後該筆從明細與統計消失
6. 重新整理頁面，資料還在
7. 切到沒有記錄的月份，顯示空狀態而不是壞掉的圖表
8. 把某筆日期改成上個月，該筆從本月消失、出現在上個月
9. 連按 `◀` 切到數個月前，點一次「本月」回到當月；此時「本月」按鈕消失，且左右箭頭**不位移**
10. 新增一筆後切到統計頁，總支出、記帳筆數、圓餅圖都反映最新資料
11. 在統計頁切換月份，三個數字與圓餅圖同步換成該月；切分頁不把月份重置回本月

### B. 內嵌表單新增的行為

12. 首次載入頁面**不會**自動聚焦金額欄、不跳鍵盤
13. 點明細某列 → 頁面捲到表單、標題變「編輯這筆」、帶入原值、金額欄取得焦點、出現「取消編輯」與「刪除這筆」
14. 該列在明細中有可見的編輯中標記
15. 點「取消編輯」→ 回新增模式、表單清空、日期回今天、刪除鈕消失
16. 存檔後表單自動清空回新增模式，日期回今天，可以直接記下一筆
17. 金額空或 0 時存檔鈕停用，且提示行寫著要補什麼；提示行出現／消失時版面不跳動

### C. 畫面與無障礙

18. **375px（iPhone SE）兩個分頁都沒有水平捲動**，明細最長的備註以省略號截斷
19. **768px 以上內容置中、最大寬 780px**
20. 所有 `input`、`button`、日期欄實測高度 ≥ 44px（月份箭頭、「本月」、分頁、六顆分類、日期、備註、存檔、刪除、明細每一列）
21. 金額、日期、備註都有**可見的** label；分類是 `fieldset` + `legend`
22. 只用鍵盤 Tab 能走完整頁，每個焦點都看得到墨綠 focus ring（含金額輸入框，ring 在外框上）
