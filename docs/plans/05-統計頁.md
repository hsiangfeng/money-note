# 統計頁：分頁與分類佔比圓餅圖

## Context

目前 App 只有一頁：月份切換＋總額、分類佔比 CSS 橫條、流水清單。要多一個統計頁，顯示當月總支出、記帳筆數與分類佔比圓餅圖。

這次動到兩條既有的拍板決策，兩條都要在 SPEC 第 10 節留紀錄：

1. **SPEC 第 6 節「圖表：不裝」翻案** —— 改用 Chart.js + vue-chartjs（使用者於 2026-08-16 拍板）。
2. **分類佔比從記帳頁移到統計頁** —— 記帳頁的 CSS 橫條刪掉，SPEC 5.1 跟著改寫。同一份 `categoryStats` 不留兩種畫法，避免日後改一邊忘一邊。

另外，統計計算目前寫死在 `src/composables/useRecords.js:68` 的 computed 裡，跟 localStorage 同一個檔。這次抽成純函式，讓統計邏輯可以脫離畫面與儲存單獨推理。

## 決策與取捨（要寫進 SPEC 第 10 節）

| 決策 | 理由 |
|---|---|
| 圖表改用 Chart.js + vue-chartjs，翻掉第 6 節「不裝」 | 使用者拍板。代價已知：兩個新依賴、canvas 渲染的文字選不起來也讀不到，所以圓餅圖旁一律附文字明細，canvas 標 `aria-hidden` |
| 分類佔比只留在統計頁，記帳頁的 CSS 橫條刪除 | 同一份資料兩種畫法要一起維護；記帳頁專心做記帳，佔比一律看統計頁 |
| 統計計算抽到 `src/utils/stats.js` 純函式 | 原本綁在 `useRecords` 的 computed 裡，跟 localStorage 同檔。抽開後統計邏輯不依賴 Vue 也不依賴儲存 |
| 分頁狀態放 App.vue 的 `ref`，不裝 Vue Router | 兩個分頁而已，維持 SPEC 第 6 節「不裝路由」 |
| 月份切換列兩個分頁共用，統計頁跟著當前檢視月份走 | 切到三月看記帳、切過去統計卻是本月，會對不上 |
| 圓餅圖與明細清單上下排，不左右並排 | 375px 下並排會把明細擠到換行。使用者要的「同時看得到、不用 hover」上下排一樣成立 |
| 統計頁的「當月支出」與 header 總額重複顯示 | 使用者明確要求統計頁要有總支出。header 是切月份的即時回饋，統計頁是與筆數並列的統計卡，層級不同 |

## 實作細節

### 依賴

```
npm i chart.js@^4.5.1 vue-chartjs@^5.3.4
```

只註冊 `ArcElement`，**不註冊 Tooltip 與 Legend** —— 資料全在旁邊的文字明細裡，tooltip 在手機上要 touch 才出得來，legend 也顯示不了金額。少註冊兩個模組。

`vue-chartjs` 的 `Doughnut` 會自己帶 `DoughnutController`，所以不用手動註冊；若 console 出現 `"doughnut" is not a registered controller` 再補上。

### CategoryPieChart.vue

```
canvas（aria-hidden，外層固定高度）
  maintainAspectRatio: false + cutout: '62%'
  plugins: { legend: { display: false } }
文字明細（真正的資料來源）
  ● 色塊   分類名稱   $金額   百分比%
```

`chartData` 用 `computed` 從 props.stats 推導 —— vue-chartjs 收到新的 data 物件會自己 update，這是「新增一筆後統計同步」能成立的關鍵，不要在裡面存一份本地副本。

沿用 `CategoryChart.vue` 現有的 grid 版面手法（`li` 用 `display: contents` 攤平，四欄共用軌道），金額欄才會對齊。

### 分類顏色

`categories.js` 六組各配一色，色塊只是輔助 —— 名稱、金額、百分比一律有文字，不靠顏色傳達任何資訊。

### App.vue 版面

底部固定 tab bar（記帳／統計），跟 FAB 一樣包在 `max-w-md` 的容器裡，桌機才不會飛到螢幕邊緣。FAB 只在記帳頁出現，`bottom` 從 `calc(1.5rem + safe-area)` 上移到 tab bar 之上；`main` 的 `pb-32` 跟著加大。

空狀態沿用現有寫法：該月沒記錄時，記帳頁維持現在的提示；統計頁顯示 `$0` / `0 筆`，圓餅圖區塊用 `v-if` 擋掉換成提示文字（空資料丟給 Chart.js 會畫出一個空白 canvas）。

## 驗收

`npm run dev`，走一遍 SPEC 第 7 節既有九條（分類佔比那條改在統計頁驗），再加這次的：

1. 記帳頁記一筆 120 飲食 → 切到統計頁，總支出與筆數含這筆，圓餅圖多一塊
2. 統計頁改月份 → 三個數字與圓餅圖同步換成該月
3. 切到沒有記錄的月份 → 統計頁顯示 $0 / 0 筆與提示，不是空白 canvas 或壞掉的圖
4. 編輯把某筆改到上個月 → 兩個分頁的統計都同步變動
5. 375px 下圓餅圖與明細不溢出、金額欄對齊
6. `npm run build` 通過
